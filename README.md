# Priyanka Sivadasan — Portfolio Website

A responsive personal portfolio made with plain HTML, CSS, and JavaScript. The site includes the supplied portrait, profile, skills, Human–Elephant Detection System project, education, internship, certifications, and contact/social links.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser. For best results, use VS Code with the Live Server extension.

## Publish with GitHub Pages
1. Sign in to GitHub as `PriyankaSivadasan22` and create a repository named `PriyankaSivadasan22.github.io` (or another repository if you prefer a project URL).
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder. Keep the folder structure unchanged.
3. For a repository named `PriyankaSivadasan22.github.io`, open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.
4. Wait for GitHub Pages to publish. The personal-site URL will be `https://priyankasivadasan22.github.io/`.

## Before publishing
- Confirm the email and phone details from the original resume; update `mailto:priyankasivadasan@gmail.com` in `index.html` if needed.
- If you later upload the Human–Elephant Detection System code, change the project link from your GitHub profile to that repository URL.
- Google Fonts are loaded online; the page still works without them using fallback fonts.
